## О демо

Интерактивный HTML-прототип отчета «Расчеты по эквайрингу» (по ТЗ — копия отчета «Обороты и сальдо по счету» с понятными для розницы заголовками: «На начало / На конец», «Ждем от банка / Поступило от банка»), который открывается панелью поверх страницы «Оплаты» раздела «Эквайринг». Переносим с прода 1 в 1.

- Статус: в работе. Сделано: страница «Оплаты» фоном, панель отчета (договоры сгруппированы по компаниям), план Б — «Журнал проверки» для поиска расхождений (на проверке).
- Язык интерфейса: русский.
- Экран: 1024×768 (ноутбук), как в демке acquiring.

### Что в отчете (по проду)

- **Панель** шириной 900 px справа поверх «Оплат». Шапка: заголовок «Расчеты по эквайрингу», «построен в ЧЧ:ММ», поиск «Найти».
- **Строка фильтра:** период («Ноябрь’26») и отбор «Все юрлица».
- **Таблица:** колонки «Сальдо начальное», «Обороты» и «Сальдо конечное», в каждой «Дебет» и «Кредит». Итоговая строка полужирным синим, ниже строки по договорам эквайринга. Копейки мельче и серым, «.00» — светло-серым.
- **Окно «Фильтр»:** период, счета, «Первая аналитика», «Точка продаж», «Наша компания», «Детализировать», «Можно отобрать» (Налоговые, валютные суммы · Обороты · Сальдо свернуто · Сальдо), «Ранее отбирались».
- **Окно «Детализировать»:** «Наша компания» → «Первая аналитика», под «Еще?»: Субсчет, Точка продаж, Дни, Недели, Месяцы, Кварталы, Годы, Документ.
- **Правая колонка иконок:** закрыть, развернуть, итоги, печать, выгрузка, ссылка, список, задачи.

### План Б: «Журнал проверки» (поиск расхождений)

Вместо маршрута «Мастер запуска» — компонент «Журнал проверки» по стандарту «Проверка отчета». Шаги маршрута «Диагностика учета эквайринговых операций» стали проверками, найденное — записями журнала, привязанными к строкам отчета.

- На панели сценариев только план Б; «Оплаты» открываются крестиком «Закрыть» на отчете.
- **Кнопка «Найти расхождения»** у заголовка (иконка Checkreport с лупой), два варианта: оранжевая и синяя бледная обводка. Сценарий «Типовое» — с подсказкой стартового этапа.
- **Идет проверка:** прогресс и шесть этапов с отметками.
- **Найдены ошибки:** дерево «компания → договор» и узел «Общее»; запись — иконка важности, текст, действия ссылками в строке (в демо — тост и пометка «исправлено»), подсказка или список документов / платежей (дата без повторов, сумма сразу за текстом), «глаз» — не учитывать. Выбор записи или стрелки ‹ › подсвечивают строку отчета; клик по строке выбирает ее запись.
- **Часть исправлена / Ошибок нет:** зачеркивание, смена цвета шапки (красный → желтый → зеленый); суммы в отчете пересчитываются после исправлений, в «Ошибок нет» — данные после всех исправлений.
- **Журнал свернут:** плашка 44 px с текстом выбранной ошибки и стрелками.

- `fonts/`, `img/` — шрифты и картинки.
- `_bp/` — материалы БП и скриншоты прода (только локально, в репозиторий не попадают).
